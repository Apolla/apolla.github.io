## 条件控制
### if-else

### 区别
1. if后面的条件的小括号可以省略
```swift
if age > 22 {
    print("age > 22")
}else{
    print("age <= 22")
}
```

### while
```swift
var n = 10

while n > 0 {

    print("n == \(n)")

    n -= 1

}
```

### repeat-while
> 相当于do-while
```swift
repeat {

    print("n == \(n)")

    n -= 1

}while ( n > 0)
```

### for
1. 闭区间运算符 a...b   a<= 值 <=b
2. 半开区间运算符 a..< b a<= 值 < b
```swift
/**
闭区间运算符 index >= 0 && index <= 3
123 0
123 1
123 2
123 3
*/
for index in 0...3 {
    print("123 \(index)")
}
/*
半开区间运算符 index >= 0 && index < 3
123 0
123 1
123 2
*/
for index in 0..<3 {
    print("123 \(index)")
}

/**
用于数组
123 a
123 j
123 b
123 c
*/
let names = ["a","j","b","c"]

for name in names[0...3] {

    print("123 \(name)")

}

```
3. 单侧区间 让区间朝一个方向尽可能远
	1. `names[0...]` 代表取值从0到数组最后一个
	2. `names[...2]` 代表取值从0到数组下标为2终止
	3. `names[..<2]` 代表取值从0到数组下标为1终止
```swift
let names = ["a","j","b","c"]
/*
123 a
123 j
123 b
123 c
*/
for name in names[0...] {
    print("123 \(name)")
}
/*
123 a
123 j
123 b
*/
for name in names[...2] {
    print("123 \(name)")
}
/*
123 a
123 j
*/
for name in names[..<2] {
    print("123 \(name)")
}
```

5. 带间隔的区间值
```swift 
let hour = 11

let interval = 2

// stride 从4开始 累加2 不超过11
// 4 6 8 10
for index in stride(from: 4, through: hour, by: interval){
    print(index)
}

```

### switch

*  `case`、`default` 后面不能写大括号{}
*   默认可以不写`break` 并不会贯穿条件
* 需要贯穿条件 可以使用`fallthrough`也可以用`,`分开
* `switch`必须要保证能处理所有情况
* `case`、`default` 后面至少要有一条语句，如果不想处理任何事情可以加`break`
* `switch`也支持`Character`、`String` 
```swift
switch age {
case 1:
    fallthrough
case 2:
    print("1 2")
default:
    print("other")
}


switch age {
case 1 , 2:
    print("1 2")
default:
    print("other")
}

let name = "jack"

switch name {

case "jack":

    print("this is jack")

default :

    print("this is other")

}
```

### where
*  使用where 过滤元素
```swift
let numbers = [1,-10,2,5,-6,89]

for item in  numbers where item > 0 {

    print("只输出大于0的\(item)")

}
```
