一、安装步骤 安装Homebrew –> 安装rvm –> 安装ruby -> 安装cocoapods

二、检查Homebrew或安装 1、查看安装的版本信息

1
2
3
4
5

brew --version

Homebrew/homebrew-core (git revision fd2e83a24e8; last commit 2023-03-06)
Homebrew/homebrew-cask (git revision c896fe8640; last commit 2023-03-06)

2、安装Homebrew 方式1：官方提供的安装方法

1

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/master/install.sh)"

方式2：使用国内的源进行安装

1

/bin/zsh -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"

安装完成后执行

1

source /Users/apple/.rvm/scripts/rvm

4、安装ruby遇到的错 （1）执行 brew install ruby 时报错

解决方法： 输入brew -v后会提示你执行两个配置命令，直接复制执行就ok了！

1
2

git config --global --add safe.directory /opt/homebrew/Library/Taps/homebrew/homebrew-core
git config --global --add safe.directory /opt/homebrew/Library/Taps/homebrew/homebrew-cask

（2）执行 rvm install 3.0.0 时报错

解决方法：

1

echo "ruby_url=https://cache.ruby-china.com/pub/ruby" > ~/.rvm/user/db

5、将ruby该版本设置默认使用

6、查询Ruby的源地址

替换国内Ruby镜像源

1
2
3

 gem sources --remove https://rubygems.org/

gem sources --add https://gems.ruby-china.com/

五、安装cocoapods

1

sudo gem install -n /usr/local/bin cocoapods

问题：执行上面命令后还是找不到pod

解决方法： 执行 sudo gem install Cocoapods 重新安装

六、pod install报错 1、执行“sudo xcode-select –switch /Applications/Xcode.app/Contents/Developer/”切换到当前Xcode路径下
