Toggle

Toggle 是表示开关状态的控件，默认的颜色风格是绿色，使用 .tint 可以改变颜色。

iOS 16/macOS 13 新增了多值开关的特性，使用一个开关可以控制一组状态。

SwiftUI 内置了几种 ToggleStyle ，效果可查看示例。

示例还演示了自定义 ToggleStyle，和前文中 Label 和 Button 自定义样式的思路是一致的。其中用到了 .matchedGeometryEffect 来实现动画效果，其用法可以参考 《SwiftUI 中的属性包装器》 中关于 @NameSpace 的介绍。

> 查看示例

Toggle 还可以方便地为绑定值添加动画，如示例中的一段代码：

1
2
3
4

Toggle(
  isOn ? "On" : "Off",
  isOn: $isOn.animation()
)

如此一来，凡是和 isOn 变量相关的视图变化，都会添加一个平滑地过渡效果。

label 和 step 在 macOS 上会展示，iOS 上则不会。

Picker

Picker 非常适合多选一的场景，使用时需要注意绑定变量和待选择视图身份的数据类型一致。

> 查看示例

比如示例中的代码：

1
2
3
4
5
6
7
8

private let weathers = Weather.mock
@State private var weather = Weather.mock.last!.name

Picker("Weather", selection: $weather) {
  ForEach(weathers, id: \.name) {
    Label($0.name, systemImage: $0.icon)
  }
}

selection 绑定的变量类型是 String，如果 ForEach 中没有将 id 指定为 \.name ，选择时视图不会更新，因为 weather 变量没有改变。weather 变量不更新的原因在于，Weather 已经实现了 Identifiable 协议，它的变量 id 为 UUID 类型，ForEach 不显示指定 id 的话，SwiftUI 会将 Weather 实例中的 id 隐式分配给相应的视图以维持视图身份的稳定。只有保持 selection 和 ForEach 中的 id 类型一致，SwiftUI 才能将数据类型一致的变量更新至 weather，从而刷新视图。

关于视图身份标识，可以参考 《SwiftUI 视图管理机制》 。

如果确实遇到数据类型不一致的情况，可以使用 .tag 手动标记。以上面的代码为例，这样写也可以：

1
2
3
4

ForEach(weathers) {
  Label($0.name, systemImage: $0.icon)
    .tag($0.name)
}

Picker 内置了多种丰富的 PickerStyle，在不同平台表现不一，而且在不同的视图中表现也有所差异。比如在 macOS 下分别在 Form 和 VStack 中使用 .radioGroup 这种样式，Picker 的布局是不一样的，在 VStack 中选择项是竖排的，而在 Form 中，如果横向空间足够，选择项是横排，如果不够，则自动切换为竖排布局。如需指定为横向布局，可以使用方法 horizontalRadioGroupLayout() 。
