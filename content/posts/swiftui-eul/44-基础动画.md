视图是数据状态的反映，状态的更新会驱动视图的更新。如果没有动画过渡，视图的变化会显得突兀。SwiftUI 提供了几种基于状态的动画，这些都是非常常用和基础的添加动画的方式。

# .animation 方法

修饰器方法 [animation(_:value:)](https://developer.apple.com/documentation/swiftui/view/animation(_:value:)) 可以方便的创建动画，它的声明如下：

```swift
func animation<V>(
    _ animation: Animation?,
    value: V
) -> some View where V : Equatable
```

当 `value` 发生变化时，将 `animation` 应用到相应的视图。`animation` 可选，默认的动画效果是平滑的淡入淡出，系统提供了多种 [Animation](https://developer.apple.com/documentation/swiftui/animation) 动画效果。

`animation` 参数为可选的，如果传入 nil，`value` 变化时，相应的视图则不会执行动画。通常用于在一组视图中应用了动画时，需要禁用某个子视图动画的场景。

<span style="background: #007BFF; color: white; padding: 3px 10px; border-radius: 5px">> 查看示例</span>

示例中的加载动画代码：

```swift
@State private var to: CGFloat = 0
@State private var rotation: CGFloat = 0

Circle()
  .trim(from: 0, to: to)
  .stroke(style: .init(lineWidth: 5, lineCap: .round))
  .foregroundColor(.blue)
  .frame(width: 40, height: 40)
  .rotationEffect(.degrees(rotation))
  .animation(
    .linear(duration: 3)
    .repeatForever(autoreverses: false),
    value: rotation
  )
  .animation(
    .linear(duration: 3)
    .repeatForever(autoreverses: false),
    value: to
  )
  .onAppear {
    to = 1.0
    rotation = 360
  }
```

当视图出现时，改变圆的绘制比例（to）和旋转角度（rotation），由于这两个属性被添加了动画，当状态的改变驱动视图更新时，就会执行指定的动画。为了便于演示，这里添加了 `repeatForever` ，表示是否重复，`autoreverses` 表示是否倒放，默认是 true。

iOS 17、macOS 14 新增了一个方法：[animation(_:body:)](https://developer.apple.com/documentation/swiftui/view/animation(_:body:))，使用是类似的：

```swift
MyView(isActive: isActive)
  .animation(.easeInOut) { content in
    content.opacity(isActive ? 1.0 : 0.0)
  }
```

该方法可以更好地控制动画的作用范围，避免意外的动画效果，更多细节可以观看 [Explore SwiftUI animation](https://developer.apple.com/videos/play/wwdc2023/10156/?time=1200)。该 Session 也提到了 [Transaction](https://developer.apple.com/documentation/swiftui/transaction) ，它是处理视图状态变更的上下文，无论是 `.animation` 还是后文提到的 `withAnimation` ，其实都是基于 Transaction 封装的便捷方法。

# 全局函数 withAnimation

全局函数 [withAnimation](https://developer.apple.com/documentation/swiftui/withanimation(_:_:)) 可以方便地在合适的时机执行动画，比如点击按钮时执行一连串的动画。

上面示例中的 animation 修饰器方法需要对多个不同的变量执行相同的代码，这显然不够方便。当然，我们也可以将分散的变量包装成一个结构体，对整个结构体实例进行状态监听。如果想偷懒，也可以使用全局函数进行改写，代码会变得更加紧凑：

```swift
Circle()
  .trim(from: 0, to: to)
  .stroke(style: .init(lineWidth: 5, lineCap: .round))
  .foregroundColor(.blue)
  .frame(width: 40, height: 40)
  .rotationEffect(.degrees(rotation))

Button("Perform") {
  withAnimation(
    .linear(duration: 3)
    .repeatForever(autoreverses: false)
  ) {
    to = 1.0
    rotation = 360
  }
```

示例中还演示了内置的部分 Animation，更多内置动画请查阅[文档](https://developer.apple.com/documentation/swiftui/animation)。

这里以如下几个方法为例解释一下弹性动画的一些参数：

```swift
static func spring(
    response: Double = 0.55,
    dampingFraction: Double = 0.825,
    blendDuration: Double = 0
) -> Animation

static func interactiveSpring(
    response: Double = 0.15,
    dampingFraction: Double = 0.86,
    blendDuration: Double = 0.25
) -> Animation

static func interpolatingSpring(
    mass: Double = 1.0,
    stiffness: Double,
    damping: Double,
    initialVelocity: Double = 0.0
) -> Animation
```

前两个方法的参数是一样的，只是默认值不同。

在解释各个参数之前，先把示例中的圆形视图想象成生活中一个挂在弹簧上的球，弹簧的运动轨迹受弹簧的弹性和初始速度以及球的质量等因素影响。

- response：弹簧硬度，值越小弹簧越硬，震动效果越明显，反之则波动幅度越大。
- dampingFraction：阻尼系数，值越大表示阻力越大，运动停止的越快。
- blendDuration：笔者尚未弄清其意义及用法，如果你对此有清晰的见解，望不吝赐教，谢谢～

最后一个方法有更多的控制参数：

- mass：物体质量，质量越大惯性越大。
- stiffness：弹簧硬度，值越大弹簧越硬，震动效果越明显，反之则波动幅度越大。
- damping：阻尼系数，值越大表示阻力越大，运动停止的越快。
- initialVelocity：弹簧的初始速度。文档中说范围是 [0, 1]，实际上这个范围可以是正负区间。正负分别表示速度和运动方向是否一致，绝对值越大，表示初始速度越大。

当然，系统也内置了一些调整好参数的弹性动画，比如 bouncy、snappy 等。

iOS 17、macOS 14 新增了一个方法：[withAnimation(_:completionCriteria:_:completion:)](https://developer.apple.com/documentation/swiftui/withanimation(_:completioncriteria:_:completion:))，它提供了一个动画完成的闭包，便于按顺序执行一些简单的动画。比如示例中所示代码：

```swift
Button("Perform") {
  withAnimation {
    circled.toggle()
  } completion: {
    withAnimation(.bouncy) {
      scaled.toggle()
    }
  }
}
```

当点击按钮时，视图会先执行改变圆角的动画，然后执行缩放动画。

理论上来说，我们可以通过嵌套来执行一系列的动画，但这样的代码不便于书写和阅读。对于一系列的复杂动画，可以使用后文介绍的相位动画和关键帧动画。

这个新方法有个 [AnimationCompletionCriteria](https://developer.apple.com/documentation/swiftui/animationcompletioncriteria?changes=latest_major) 类型的参数 `completionCriteria`，它可以被指定为以下值：

- logicallyComplete
- removed

`removed` 表示动画完全完成之后才去执行下一个动画，通常这是符合常理的。但有时候我们可能正在执行一个弹簧动画，动画的长尾时间会非常长，但弹簧动画的后期效果却不那么明显，这个等待过程的意义不大，只会阻碍后续动画的执行，导致不好的用户体验。所以系统默认的值为 `logicallyComplete`，即逻辑上的动画结束，即使弹簧动画仍然处于运动的长尾时间内，系统就会执行下一个动画，以减少无谓的等待。

# 绑定值动画

Binding 提供了便利的 `.animation` 方法，当绑定值发生改变时，会执行相应的动画。

```swift
Toggle(
  "blooming",
  isOn: $blooming
    .animation(
      .spring(response: 0.3, dampingFraction: 0.3)
    )
)
```

# 相位动画

“相位”是物理学、数学中的一个概念，通常表示物体周期性运动的阶段。相位动画，顾名思义，表示的是视图在某个阶段内的动画。

[PhaseAnimator](https://developer.apple.com/documentation/swiftui/phaseanimator) 遵循 View 协议，我们可以直接使用它来创建具有相位动画的视图（后文提到的 [KeyframeAnimator](https://developer.apple.com/documentation/swiftui/keyframeanimator) 是类似的）。也可以直接使用 SwiftUI 提供的 modifer（iOS 17、macOS 14）：

- [phaseAnimator(_:content:animation:)](https://developer.apple.com/documentation/swiftui/view/phaseanimator(_:content:animation:))
- [phaseAnimator(_:trigger:content:animation:)](https://developer.apple.com/documentation/swiftui/view/phaseanimator(_:trigger:content:animation:))

示例中使用第二个方法演示了一个 like 动画，主要代码如下：

```swift
Button {
  like.toggle()
} label: {
  Image(systemName: like ? "heart.fill" : "heart")
    .symbolRenderingMode(.multicolor)
    .phaseAnimator(
      LikePhase.allCases, // phase
      trigger: like // trigger
    ) { content, phase in // content
      content
        .offset(y: phase.offsetY(like))
        .scaleEffect(phase.scale(like))
    } animation: { phase in // animation
      phase.animation(like)
    }
}

fileprivate enum LikePhase: CaseIterable {
  case toggle
  case move
  case reset

  func offsetY(_ like: Bool) -> CGFloat {
    self == .move && like ? -15 : 0
  }
  
  func scale(_ like: Bool) -> CGFloat {
    self == .move && like ? 1.2 : 1.0
  }
  
  func animation(_ like: Bool) -> Animation {
    self == .move && like ? .bouncy : .default
  }
}
```

参数解释：

- phase：相位动画各个阶段的序列。比如我们这里指定的是 `LikePhase` 的所有枚举值，如果只想针对其中的某些阶段执行动画，那么可以根据实际需要移除相应的枚举值。
- trigger：用于触发动画。
- content：闭包内返回当前视图（content），以及当前的阶段（phase）。
- animation：闭包内返回过渡到下一个阶段的动画，如果返回 nil，则禁用动画。

另一个方法 `phaseAnimator(_:content:animation:)` 使用是类似的，只不过没有了 trigger 来触发动画，视图会根据指定的 phase 周而复始地执行动画。具体效果可以 copy 代码后自行实践，只需要移除 trigger 参数并将 like 变量的初始值指定为 true 即可。

# 关键帧动画

在动画和视频制作中，关键帧是一种特殊的帧，它定义了一个特定的点，动画在这个点应该处于特定的状态。在两个关键帧之间，SwiftUI 会对视图进行插值运算，以生成顺滑的动画效果。

比起相位动画，关键帧动画的控制更为复杂和精细。与相位动画类似，SwiftUI 提供了如下 modifier：

- [keyframeAnimator(initialValue:repeating:content:keyframes:)](https://developer.apple.com/documentation/swiftui/view/keyframeanimator(initialvalue:repeating:content:keyframes:))
- [keyframeAnimator(initialValue:trigger:content:keyframes:)](https://developer.apple.com/documentation/swiftui/view/keyframeanimator(initialvalue:trigger:content:keyframes:))

参数释义：

- `initialValue`：帧动画的初始值。
- `repeating`：是否重复。
- `trigger`：用于触发动画。
- `content`：闭包内返回当前视图（content），以及当前差值（value）。
- `keyframes`：随时间变化的关键帧。

`keyframes` 定义了动画的行为，系统内置了以下几种常用的关键帧：

- [CubicKeyframe](https://developer.apple.com/documentation/swiftui/cubickeyframe)：使用三次曲线平滑**插值**的关键帧。
- [LinearKeyframe](https://developer.apple.com/documentation/swiftui/linearkeyframe)：使用简单线性**插值**的关键帧。
- [SpringKeyframe](https://developer.apple.com/documentation/swiftui/springkeyframe)：使用弹簧动画**插值**到给定值的关键帧。
- [MoveKeyframe](https://developer.apple.com/documentation/swiftui/movekeyframe)：一个**无插值**，立即移动到给定值的关键帧。

前几种比较常用，它们都提供了平滑的过渡效果，MoveKeyframe 几乎不会用到，它呈现的视觉效果就是没有任何动画的突变。

# 更多示例

示例中还演示了一个渐变的 “WWDC23” 文字，这里说一下实现思路：

1. 文字背景是一个渐变区域，通过定时器不断地触发 updatePoints 方法，让 startPoint 和 endPoint 这两个控制点在渐变矩形区域的边上缓慢前行，从而实现渐变区域的动画效果。
2. 使用 mask 方法将文字作为渐变区域的遮罩，以此实现渐变色文字。
3. 定时器事件触发时，同时更新 degrees 变量，实现文字的 3d 旋转效果。

当然，这个动画还有很多改进的空间，以上仅为抛砖引玉。

这个示例的渐变动画是通过更新 startPoint 和 endPoint 的值来驱动视图更新实现的，稍微有点复杂。在 iOS 17、macOS 14 之后，我们可以直接通过改变 colors 来实现动画：

```swift
LinearGradient(
  colors: animate ? [.orange, .red, .purple] : [.green, .teal, .blue],
  startPoint: .topLeading,
  endPoint: .bottomTrailing
)
```
