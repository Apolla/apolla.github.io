# 手势的状态监听

《常见手势》 演示了通过 `.onChanged` 和 `.onEnded` 分别监听手势的变化和结束。

除此以外，还能使用属性包装器 [@GestureState](https://developer.apple.com/documentation/swiftui/gesturestate) 追踪手势的状态变化，前文已经介绍过了，请参考 《SwiftUI 中的属性包装器》 中关于 @GestureState 的部分。

# 限定手势范围

[contentShape(_:eoFill:)](https://developer.apple.com/documentation/swiftui/view/contentshape(_:eofill:)) 可以将视图的手势可交互区域限定在指定形状内。

如示例所示，方形区域内添加了一个单击手势，但只有点击三角形区域内时手势才会生效。

```swift
Rectangle()
  .fill(tapped ? .red : .blue)
  .frame(height: 200)
  .contentShape(Triangle())
  .onTapGesture {
    tapped.toggle()
  }
  // 辅助线
  .overlay {
    Triangle()
      .stroke(.secondary)
  }
```

# 多个手势的处理

## 指定优先级

多个手势容易导致冲突，比如示例中实现了一个带有手势的橙色视图：

```swift
private var orangeRectangle: some View {
  Rectangle()
    .fill(.orange)
    .padding(50)
    .onTapGesture {
      tappedColor = .orange
    }
}
```

当将它和其它视图叠加时，会拦截蓝色背景的手势：

```swift
ZStack {
  Rectangle()
    .fill(.blue)
  
  orangeRectangle
}
.frame(height: 200)
.onTapGesture {
  tappedColor = .blue
}
```

如果希望能够保留橙色区域的可交互性，又能够穿透点击至蓝色背景区域，可使用 [.highPriorityGesture](https://developer.apple.com/documentation/swiftui/view/highprioritygesture(_:including:)) 方法提升蓝色视图的优先级来实现：

```diff
- .onTapGesture {
-   tappedColor = .blue
- }
+ .highPriorityGesture(
+   TapGesture()
+     .onEnded {
+       tappedColor = .blue
+     }
+ )
```

## GestureMask

使用 [gesture(_:including:)](https://developer.apple.com/documentation/swiftui/zstack/gesture(_:including:)) 方法为视图添加手势时，可以传入一个 [GestureMask](https://developer.apple.com/documentation/swiftui/gesturemask) 类型的参数来控制管理视图层级内的手势行为。

GestureMask 内置了以下几种选项：

- .all：添加手势的视图和子视图都能响应手势。
- .gesture：只有添加手势的视图能响应手势，子视图无法响应。
- .subviews：只有子视图能响应手势，添加手势的视图无法响应。
- .none：添加手势的视图和子视图都不能响应手势。

## 屏幕边缘系统手势的处理

iOS 设备内置了一些系统手势，比如从屏幕顶部下拉通知中心，从屏幕底部上滑将 app 退至后台等。如果用户正停留在某个全屏界面专注于游戏或者绘画，由于误触激活了系统手势行为，势必导致不好的用户体验。

[defersSystemGestures(on:)](https://developer.apple.com/documentation/swiftui/view/deferssystemgestures(on:)) 可以让自定义手势的优先级高于系统手势，比如示例中为全屏界面添加了一个拖拽手势，当下拉通知中心或者上滑至 app 后台界面时，会激活顶部或底部的指示条供用户二次选择是否激活系统手势。

## 手势的组合

一个视图可能会添加多个手势触发不同的事件，这时需要使用恰当的组合来处理这些手势。SwiftUI 提供了以下三种手势组合：

- SimultaneousGesture：同时，多个手势可以同时响应。
- SequenceGesture：有序，多个手势按照既定顺序执行
- ExclusiveGesture：互斥，即同一时刻只有一个手势会生效。

<span style="background: #007BFF; color: white; padding: 3px 10px; border-radius: 5px">> 查看示例</span>

下面的代码表示手势绑定的视图可以在旋转的同时进行缩放，使用 `.simultaneously` 方法组合手势和使用 SimultaneousGesture 结构体进行构造是一样的，SequenceGesture 和 ExclusiveGesture 是类似的。

```swift
.gesture(
  RotationGesture()
    .simultaneously(
      with: MagnificationGesture()
    )
)
```

长按之后才能激活拖拽手势：

```swift
.gesture(
  LongPressGesture(minimumDuration: 1)
    .sequenced(
      before: DragGesture()
    )
)
```

单击和缩放手势只能响应其中一个：

```swift
.gesture(
  TapGesture()
    .exclusively(
      before: MagnificationGesture()
    )
)
```
