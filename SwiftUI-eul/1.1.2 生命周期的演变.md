iOS 13 之前，app 的入口以及生命周期方法由 [UIApplicationDelegate](https://developer.apple.com/documentation/uikit/uiapplicationdelegate) 协议定义，通常我们使用 [UIWindow](https://developer.apple.com/documentation/uikit/uiwindow) 实例作为呈现界面和分发事件的窗口。

iOS 13 开始，iPad 支持多窗口模式。 臃肿的 AppDelegate 不堪重负，于是它将各个窗口的管理工作分配给 [UISceneDelegate](https://developer.apple.com/documentation/uikit/uiscenedelegate) 实例。

iOS 14 新增了 SwiftUI 专属的 [App](https://developer.apple.com/documentation/swiftui/app) 协议，它定义了 app 的结构和行为。创建一个 SwiftUI 项目时，Xcode 默认实现了一个 App 实例：

```swift
@main
struct MyApp: App {
  var body: some Scene {
    WindowGroup {
      ContentView()
    }
  }
}
```

在 `body` 内可以声明一个或多个运行场景（[Scene](https://developer.apple.com/documentation/swiftui/scene)），app 就是由这些场景构成的。它们在同一个 app 进程中并行运行，但每个场景有自己的生命周期，各自管理自身的视图和状态。

UIKit 时代臃肿的 AppDelegate 不复存在，那么如何监听 app 内各个场景的状态变化呢？SwiftUI 可以通过修饰器 [.onChange](https://developer.apple.com/documentation/swiftui/list/onchange(of:perform:)) 监听环境变量 [scenePhase](https://developer.apple.com/documentation/swiftui/environmentvalues/scenephase) 的值来实现。view 可以通过如下代码获取 scenePhase，它表示的是该 view 所属的场景的状态。

```swift
@Environment(\.scenePhase) private var scenePhase
```

据笔者测试，sheet 呈现的视图并没有将场景的 scenePhase 传递过来，不过我们可以手动注入该环境变量，参考代码：

```swift
struct ContentView: View {
  
  @Environment(\.scenePhase) private var scenePhase
  @State private var isShowingSheet = false
  
  var body: some View {
    Text("")
      .sheet(isPresented: $isShowingSheet) {
        SheetView()
          .environment(\.scenePhase, scenePhase)
      }
  }
}
```

如果不想依赖于环境变量，还可以通过订阅通知来获取更详细的状态变化：

```swift
#if os(iOS)
typealias Application = UIApplication
#elseif os(macOS)
typealias Application = NSApplication
#endif

struct SampleSceneLifeCycle: View {
  
  @Environment(\.scenePhase) private var scenePhase
  @State private var phases = [String]()
  
  var body: some View {
    Text("")
    .onReceive(
      NotificationCenter.default.publisher(
        for: Application.willResignActiveNotification)
    ) { value in
      printLog(value.name.rawValue)
    }
  }
}
```

ScenePhase 目前只有三个枚举值：*.inactive*、*.background*、*.active*，它有一定的局限性，比如处理内存警告、远程通知等，则仍需借助 UIApplicationDelegate、NSApplicationDelegate 的能力，SwiftUI 提供了属性包装器 [UIApplicationDelegateAdaptor](https://developer.apple.com/documentation/swiftui/uiapplicationdelegateadaptor)、[NSApplicationDelegateAdaptor](https://developer.apple.com/documentation/swiftui/nsapplicationdelegateadaptor) 来解决这个问题。

使用上也非常简单，下面以 iOS 平台的 UIApplicationDelegateAdaptor 的使用为例，首先声明如下类：

```swift
class UIAppDelegate: NSObject, UIApplicationDelegate {
  
  func application(
    _ application: UIApplication,
    didRegisterForRemoteNotificationsWithDeviceToken deviceToken: Data
  ) {
    
  }
  
  // ...
}
```

该类中可以使用 UIApplicationDelegate 提供的方法，然后只需在 app 入口处使用属性包装器声明该类即可：

```swift
@main
struct MyAppApp: App {
  
  @UIApplicationDelegateAdaptor private var uiAppDelegate: UIAppDelegate
  
  var body: some Scene {
    WindowGroup {
      ContentView()
    }
  }
}
```

如果需要监听该类的状态变化，使之遵循 [ObservableObject](https://developer.apple.com/documentation/combine/observableobject) 协议即可：

```swift
class UIAppDelegate: NSObject, UIApplicationDelegate, ObservableObject {
  
}
```

SwiftUI 会自动将 UIAppDelegate 实例注入环境变量，app 的任何视图都可以通过环境变量监听实例的状态：

```swift
@EnvironmentObject private var uiAppDelegate: UIAppDelegate
```
