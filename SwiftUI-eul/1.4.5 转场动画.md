# 内置转场动画

转场动画用于视图的添加、移除，使用如下方法为视图添加转场：

```swift
func transition(_ t: AnyTransition) -> some View
```

[AnyTransition](https://developer.apple.com/documentation/swiftui/anytransition) 是一个擦除类型信息的转场类型，它提供了一些常用的转场，比如缩放、移动等，使用简单，具体效果参见示例。

# 转场组合

AnyTransition 可以通过如下三种方法进行组合：

- `.combined`：将多个转场组合在一起，返回一个新的转场。

  ```swift
  .transition(
    .opacity
      .combined(with: .scale(scale: 0.1))
      .combined(with: .offset(x: -60))
  )
  ```

- `.asymmetric`：非对称转场。系统内置的常用转场，默认是对称的，比如 `.scale` ，添加视图时放大，移除时则缩小。`.asymmetric` 则可以分别指定添加和移除视图时的转场动画，实现非对称转场。

  ```swift
  .transition(
    .asymmetric(
      insertion:
          .offset(x: -30)
          .combined(with: .opacity),
      removal:
          .offset(x: 30)
          .combined(with: .opacity)
    )
  )
  ```

- `.animation`：为转场添加指定动画效果。

  ```swift
  .transition(
    .scale
      .animation(
        .spring(response: 0.3, dampingFraction: 0.2)
      )
  )
  ```

# 自定义转场

AnyTransition 提供了一个方法用于自定义转场：

```swift
static func modifier<E>(
    active: E,
    identity: E
) -> AnyTransition where E : ViewModifier
```

系统内置转场没有提供旋转效果，我们来自己实现一个。

先定义上面方法所需要的 ViewModifier：

```swift
fileprivate struct CustomTransitionEffect: ViewModifier {
  let degrees: Double
  
  func body(content: Content) -> some View {
    content
      .rotationEffect(.degrees(degrees))
  }
}
```

然后扩展 AnyTransition，添加自定义转场，这里还组合使用了系统内置的转场：

```swift
fileprivate extension AnyTransition {
  
  static var customTransiton: AnyTransition {
    .modifier(
      active: CustomTransitionEffect(degrees: 0),
      identity: CustomTransitionEffect(degrees: 360)
    )
    .combined(with: .opacity)
    .combined(with: .scale)
    .animation(
      .spring(response: 0.3, dampingFraction: 0.2)
    )
  }
}
```

调用：

```swift
if show {
  Image(systemName: "circle.hexagongrid.fill")
    .renderingMode(.original)
    .font(.largeTitle)
    .transition(.customTransiton)
}
```

iOS 17、macOS 14 新增了一个转场协议 [Transition](https://developer.apple.com/documentation/swiftui/transition)，它支持更加精细的控制转场动画。文档中也给出了代码示例，使用比较简单，这里就不再赘述了。
